# Compute power of quadratic form test (R implementation)

Compute power of quadratic form test (R implementation)

## Usage

``` r
getpow_qf_r(om0, om1, emat)
```

## Arguments

- om0:

  Null hypothesis q x q covariance matrix

- om1:

  Alternative q x q covariance matrix

- emat:

  q x nrep standard normal draws

## Value

Power scalar
