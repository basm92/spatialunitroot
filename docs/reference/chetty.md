# Chetty et al. (2014) Commuting Zone Data

## Format

A data frame with 707 observations and 39 variables:

- state:

  State abbreviation

- cz:

  Commuting zone identifier

- s_1:

  Latitude (decimal degrees)

- s_2:

  Longitude (decimal degrees)

- am:

  Absolute upward mobility

- fracblack:

  Fraction black

- racseg:

  Racial segregation

- segpov25:

  Segregation of poverty

- fraccom15:

  Fraction commuting \< 15 min

- hipc:

  Household income per capita

- gini:

  Gini coefficient
